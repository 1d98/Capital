# Капитал

Настольное приложение для локального учёта и аналитики личного капитала. Позволяет вести активы и обязательства, следить за динамикой чистого капитала, планировать платежи и строить прогнозы.

## Возможности

- Учёт недвижимости, вкладов, инвестиций, наличных, транспорта, криптовалют и других активов.
- Учёт кредитов и обязательств, календарь предстоящих платежей.
- Дашборд с ключевыми показателями, историей и структурой капитала.
- Пересчёт в BYN по курсам НБРБ и обновление цен криптовалют через CoinGecko.
- Прогнозирование капитала с учётом ожидаемой доходности.
- Экспорт данных в JSON и CSV, резервное копирование SQLite и восстановление из JSON.
- Светлая и тёмная темы, русский и английский интерфейсы.

## Технологии

React, TypeScript, Vite, Electron, SQLite (`better-sqlite3`), Tailwind CSS, Recharts и Motion.

## Требования

- Node.js 22 или новее
- npm 10 или новее

## Установка и запуск

```bash
npm ci
npm run dev
```

Команда `npm run dev` одновременно запускает Vite и Electron. Для запуска только веб-интерфейса используйте:

```bash
npm run dev:web
```

## Сборка приложения

```bash
npm run dist
```

Локальная сборка выполняется для текущей операционной системы и архитектуры. Для Windows создаётся NSIS-установщик x64, для macOS — DMG и ZIP. Автоматический релиз собирает пакеты macOS для Intel (x64) и Apple Silicon (arm64). Готовые файлы сохраняются в каталоге `release`, который исключён из Git.

## Публикация релиза

Версия в `package.json` должна соответствовать тегу релиза. Например, для версии `1.0.1`:

```bash
npm version 1.0.1
git push origin main --follow-tags
```

После отправки тега `v1.0.1` workflow `.github/workflows/release.yml` проверит код, соберёт пакеты на Windows и macOS и опубликует их в GitHub Release. Примечания к релизу генерируются автоматически.

Сборки не подписываются сертификатами разработчика, поэтому Windows SmartScreen или macOS Gatekeeper могут показывать предупреждение при первом запуске.

## Данные и приватность

Данные хранятся локально в SQLite в пользовательском каталоге Electron. При первом запуске приложение создаёт демонстрационный портфель; его можно заменить собственными данными или очистить в настройках.

Обновление валютных и криптовалютных курсов требует доступа к сети. Внешние запросы можно отключить в настройках приложения. Файлы баз данных, резервные копии и локальные переменные окружения исключены из репозитория.
